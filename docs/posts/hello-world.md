## 为什么要写博客

工作几年之后，我越来越觉得：**能讲清楚，才算真的学会**。

平时查资料、写代码、解决问题，知识来得又快又碎。如果不整理，过一阵子就只剩一个模糊的印象。写博客是一种很好的「输出倒逼输入」：

1. 把零散的经验整理成结构化的文字
2. 逼自己把「大概是这样」变成「确定是这样」
3. 留下可检索的记录，下一次直接翻自己的文章

## 这个博客会写什么

| 分类 | 内容 |
| --- | --- |
| 前端 | Vue、TypeScript、工程化、构建工具 |
| 后端 | Node.js、数据库、部署运维 |
| 读书 | 技术书与非技术书的读书笔记 |
| 随笔 | 一些不一定有用的胡思乱想 |

## 用了什么技术

这个站点本身也很简单：

- **VuePress 2**：基于 Vite 的静态站点生成器，Markdown 写内容，Vue 写组件
- **vuepress-theme-hope**：功能齐全的博客主题，自带文章列表、分类、标签、时间线、搜索
- **GitHub Pages**：免费托管，推送代码即自动构建发布

整个过程零服务器、零费用。
